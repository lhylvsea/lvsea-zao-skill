# 创建交接模板

```markdown
# Creation Handoff

## Result
- skill / version / owner
- one-line job
- local path / publication status

## Reference skills studied
- source link, why shortlisted, dated signal, learned mechanism, destination in this package

## Absorbed and rejected
- keep: ...
- adapt: ...
- reject: ...
- invent: ...

## Advantages and evidence
- [design advantage] ...
- [validated advantage] ...
- [hypothesis] ... (missing evidence)

## Verification and limits
- package / trigger / IR / context / release / install results
- missing evidence
- deliberately excluded permissions or actions
```

不要写“最好”“世界级”“全面优于某方案”，除非有公平、隔离、可复现的对比证据。清单差异本身只能称为 `design advantage`，不能自动称为结果优势。
